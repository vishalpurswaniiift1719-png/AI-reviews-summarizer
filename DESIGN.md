## Brand & Style

This design system establishes an executive-grade digest and analytical command surface for Noon e-commerce operational leadership. The product bridges customer sentiment (app store reviews, social feedback, delivery CSAT) with concrete engineering, catalog, and logistics telemetry.

### Personality & Tone
- **Authoritative & Objective:** High-signal density with zero frivolous decoration. Data speaks directly through precise typographic hierarchies.
- **Urgent yet Composed:** Strategic use of Noon Yellow as an operational focal point, balanced against structured charcoal neutrals to maintain clarity during high-stakes executive scans.
- **Algorithmic Transparency:** Direct indicators for Model Context Protocol (MCP) data syncs, automated classification confidence, and dynamic source lineage (Google Play Store, Gmail executive escalations, Google Docs briefings).

### Visual Direction: Executive Intelligence Stream
The aesthetic combines the structural discipline of high-performance fintech dashboards with the readable cadence of premium editorial briefs. Surface separation relies on hairline borders, muted slate fills, and precise metric callouts rather than heavy elevation or gratuitous drop shadows. Visual noise is minimized to support under-two-minute executive catch-ups on mobile devices.

## Colors

The palette leverages Noon's vibrant signature yellow paired with a high-contrast charcoal black base, grounded by rigorous functional neutrals and high-clarity operational status tokens.

### Core Swatches
- **Primary (`#FEEE00`):** Noon Yellow. Reserved exclusively for primary brand focal anchors, active primary action buttons, key summary highlights, and unread briefing indicators. Text placed on this yellow is strictly the deep charcoal token (`#1A1A1A`) to ensure WCAG AAA legibility.
- **Secondary / Canvas Base (`#1A1A1A`):** Deep Charcoal Black. Used for primary typography, dark-mode header blocks, and high-contrast analytical metric values.
- **Tertiary (`#0D9488`):** Deep Teal Slate. Serves as a grounding accent for integrated data feeds, MCP agent triggers, and metadata links.
- **Neutral / Slate (`#64748B`):** Cool slate for structural hair lines, secondary labels, timestamp metadata, and inactive state borders.

### Functional Status Tokens
- **Positive / CSAT Growth (`#059669`):** Emerald positive tone for sentiment recovery, 5-star ratings, and resolved delivery bottlenecks.
- **Warning / Operational Risk (`#D97706`):** Amber tone for pending SLA spikes, return anomalies, and fluctuating app ratings (3-star alerts).
- **Critical / Escalation (`#DC2626`):** Crimson alert tone for 1-star review surges, payment gateway errors, and critical delivery drop-offs.
- **Surface Tints:**
  - Surface Background: `#F8FAFC`
  - Card Surface: `#FFFFFF`
  - Subtle Inset: `#F1F5F9`
  - Hairline Border: `#E2E8F0`

## Typography

The type ecosystem deploys a high-efficiency triad:
1. **Outfit:** Modern, sculpted, geometric sans-serif for executive headers, top-level pulse indices, and key metric numbers. Delivers clean consumer brand polish.
2. **Inter:** High-legibility grotesque workhorse for synthesis summaries, executive bullet points, customer review excerpts, and multi-line analytical briefs.
3. **JetBrains Mono:** Code-grade monospace strictly reserved for Play Store version numbers (`v12.4.1`), MCP sync latency stamps, sentiment drift percentages (`+4.2%`), and issue tracking IDs (`#NOON-REV-849`).

### Hierarchy Guidelines
- Use `data-mono-sm` uppercase for tracking category markers (e.g., `LOGISTICS • LAST-MILE`, `CHECKOUT • GCC`).
- App review quotations must be set in `body-md` italicized with attribution tags in `label-sm`.
- Quantitative KPI shifts (e.g., NPS, Play Store 30-day moving average) combine `headline-lg` (Outfit) for the value with `data-mono-md` (JetBrains Mono) for the delta pill.

## Layout & Spacing

This design system uses a strict mobile-first viewport architecture that fluidly expands into an executive command grid on tablet and desktop surfaces.

### Layout Mechanics
- **Mobile (<768px):** Single-column stacked stream. 16px lateral margin. Dense vertical cadence prioritizing rapid vertical skimming through metric summaries, top app reviews, and action items.
- **Tablet (768px - 1023px):** 6-column grid with 20px gutters. KPI row splits into dual columns; pulse highlights occupy full width.
- **Desktop (≥1024px):** 12-column fixed-fluid hybrid grid (max content container width `1280px`).
  - Columns 1-8: Primary Digest Stream (Key feedback themes, sentiment shifts, high-impact review feeds).
  - Columns 9-12: Operational Pulse Sidebar (MCP Workspace integration logs, Gmail escalation queue, Play Store live ratings, action assignees).

### Spacing Rhythms
- Card internal padding is uniformly set to `space-base` (16px) on mobile, upgrading to `space-lg` (20px) on desktop surfaces.
- Micro-margins within metric rows use `space-xs` (6px) to maintain immediate semantic association between values and indicators.
- Major editorial segment dividers rely on `space-2xl` (40px) to provide natural executive pause points between operational domains.

## Elevation & Depth

This design system eschews multi-stage skeuomorphic or floating drop shadows in favor of a low-elevation, high-clarity **flat-tonal architectural stack**. Depth is generated through crisp hairline boundaries, targeted surface color variations, and deliberate ambient contrast.

### Stacking Model
- **Base Canvas:** `#F8FAFC` (Cool Off-White). Neutral background establishing a clinical, clear canvas.
- **Layer 1 (Card & Module Surfaces):** `#FFFFFF` bordered with a 1px continuous hairline of `#E2E8F0`. No shadow on standard restful states.
- **Layer 2 (Inset Metric & Code Wells):** `#F1F5F9`. Recessed background tone for sentiment quote boxes, review snippet cards, and mono metadata strips.
- **Layer 3 (Floating Action & Executive Sticky Bar):** `#FFFFFF` with a 1px border `#CBD5E1` and an ambient, ultra-diffused floor drop: `0px 4px 20px -2px rgba(26, 26, 26, 0.06)`.
- **Active & Focus Highlights:** Interactive cards display a sharp border shift to `#1A1A1A` with a micro-offset `0px 0px 0px 1px #1A1A1A` ring, accompanied by a subtle left-edge 3px marker in Noon Yellow (`#FEEE00`).

## Shapes

The geometric identity relies on a compact, disciplined **Soft (`1`)** corner radius scale. This reflects institutional efficiency and high data throughput, avoiding childish bubbly aesthetics while preventing brutalist edge harshness.

### Corner Rules
- **Base Components (`rounded` - 4px):** Operational tags, JetBrains Mono metric delta badges, input fields, checkboxes, and inline code pills.
- **Cards & Data Modules (`rounded-lg` - 8px):** Primary content containers, Play Store feedback tiles, and analytical chart wrappers.
- **Executive Modals & Digest Sections (`rounded-xl` - 12px):** Top-level alert sheets, Gmail escalation previews, and filter drawers.
- **Pill Counters (`rounded-full`):** Category counter numbers, status dots, and live MCP sync health indicators.

## Components

### 1. Buttons
- **Primary Action (Brand Push):** Background `#FEEE00`, text `#1A1A1A`, font Outfit Semibold 14px, 8px border radius, zero shadow. Hover state shifts to `#E5D600`. Active state scales down to `0.98`.
- **Secondary Executive Action:** Background `#1A1A1A`, text `#FFFFFF`, font Inter Medium 14px.
- **Ghost/Tertiary:** Transparent background, 1px border `#E2E8F0`, text `#64748B`. Hover shifts to `#F1F5F9` with text `#1A1A1A`.

### 2. Metric & Sentiment Badges
- **Format:** Micro pill containers using 4px radius and `data-mono-sm` typography.
- **Positive Sentiment Pill:** Faint emerald surface (`#ECFDF5`), emerald text (`#047857`), 1px border `#A7F3D0`. Prefixed with `▲`.
- **Negative Sentiment Pill:** Faint crimson surface (`#FEF2F2`), crimson text (`#B91C1C`), 1px border `#FECACA`. Prefixed with `▼`.
- **Neutral / Latency Pill:** Surface `#F1F5F9`, slate text `#475569`, 1px border `#E2E8F0`.

### 3. Customer Review Intelligence Cards
- White background (`#FFFFFF`) with 1px border `#E2E8F0` and 8px border radius.
- Header row containing: Play Store star rating visualization (gold stars `#EAB308`), reviewer locale (`SA`, `AE`, `EG`), review submission time, and app version tag (`JetBrains Mono`).
- Body text set in `body-md` (`#1A1A1A`). Automated AI topic pills (e.g., `Delivery Delay`, `ApplePay Error`, `Driver Etiquette`) positioned directly underneath the body in `label-sm`.
- Quick-action footer: "Export to Doc", "Assign to Team Lead", and "View Trace".

### 4. Tag Pills & Chips
- Compact height (24px), horizontal padding 8px.
- Inactive: Background `#F1F5F9`, text `#475569`.
- Active Filter: Background `#1A1A1A`, text `#FFFFFF`.
- Noon Accent Tag: Background `#FEF9C3` (10% yellow tint), text `#854D0E`, 1px border `#FDE047`.

### 5. Input Fields & Search Bars
- Background `#FFFFFF`, 1px border `#CBD5E1`, 4px corner radius. Focus states exhibit a solid `#1A1A1A` perimeter border with zero blur spread.
- Pre-appended search filters include monospace scope selector chips (e.g., `scope:play-store`, `tag:checkout`).

### 6. Cards & Digest Section Blocks
- Segment headers feature an 18px Outfit bold title accompanied by a Noon Yellow square bullet (`4px × 4px` inline block) indicating real-time feed updates.
- Section boundaries utilize a subtle 1px divider rule `#E2E8F0` with clear vertical separation.

### 7. MCP Integration Status Indicators (Google Workspace & Play Store)
- Special purpose executive status tile.
- Dual-indicator row displaying:
  - Tool agent state (e.g., `mcp:gdrive-pulse-doc-sync`, `mcp:gmail-escalations-query`).
  - Real-time pulse dot: animated `#059669` green ping for connected systems; steady `#D97706` amber for indexing; `#DC2626` red for expired auth tokens.
  - One-click triggers to compile the current digest directly into a pre-formatted Google Doc or dispatch an executive briefing via Gmail.
